# Early distribution and limitations

- GitHub is the early channel until Google Play publication. Read version-specific notes on [Releases](https://github.com/toyo-craft/ttdraw/releases).
- Android 7.0 (API24) or later is targeted; identical behavior on every device and OS version is not guaranteed.
- See each release for its verification scope and further notes. Device-specific performance, accessibility, and actual Play migration results are not guaranteed without a stated verification result.
- Regular sketches above 30 are automatically cleaned up from the oldest. Favorites and templates are excluded.
- PNG is an image of the current viewport. Use TTD for a backup of editable saved data.
- The current version has no login, ads, in-app payments, or synchronization to the Provider's cloud. Future features are not represented as currently available.
- Development APKs may have a different signature from distribution APKs even with the same app ID. Back up data before considering removal or migration.
- The Web version is not publicly distributed. Use authorized sources and do not enter private data into unofficial copies.

Use [Issues](https://github.com/toyo-craft/ttdraw/issues) for public reports and [info@toyo-craft.net](mailto:info@toyo-craft.net) for private inquiries.
