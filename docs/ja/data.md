# 保存・バックアップ・移行

スケッチは端末内へ保存します。提供者のクラウドへ自動同期する機能はありません。ログインや課金契約で保存される仕組みも現行版にはありません。

## 通常スケッチは30件

通常の非お気に入りスケッチは30件を上限に自動整理します。保存や取込みの確定後に上限を超えた場合、更新日時の古い通常スケッチが対象になります。お気に入り・テンプレート・読み込めない保存データは整理の対象外です。既存データを読み込んだだけで、一括整理するものではありません。

## TTDでバックアップ

- 一覧のメニューから「エクスポート」を選ぶと、全保存データを1つのTTD（`.ttd`）ファイルへ書き出せます。
- 通常・お気に入りのスケッチ、テンプレート、対応する画像素材を含みます。言語等の設定やUndo履歴は移行対象ではありません。
- 重要なスケッチは定期的に書き出し、アプリとは別の安全な保存先へ置いてください。ファイルを保持するだけでなく、必要なときに取り込めることも確認してください。
- 「インポート」は既存データへの追記です。同じファイルを再度取り込むと重複する場合があります。通常30件を超える取込みは、表示された整理件数と確認内容を読んでから確定してください。

## PNGと共有

PNGは現在表示中のキャンバス範囲を画像化します。画面外も含む編集データ全体の保存ではありません。再編集や全データ移行にはTTDを使います。共有先アプリやクリップボードへ渡した内容、書出し先のファイルは、それぞれの保存先で管理してください。

アプリの削除やOSのデータ消去で端末内データが失われる場合があります。OS提供のバックアップは別機能であり、提供者によるクラウド保存ではありません。[プライバシーポリシー](https://github.com/toyo-craft/ttdraw/blob/main/docs/ja/privacy.md)も確認してください。

公開できないデータの相談は[info@toyo-craft.net](mailto:info@toyo-craft.net)へ。公開Issueには添付しないでください。
