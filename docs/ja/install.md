# インストールと更新

## 初めて使う

1. [TTDraw Releases](https://github.com/toyo-craft/ttdraw/releases)から最新版の説明を読み、Android用APKを取得します。
2. Android 7.0（API24）以降の端末でAPKを開き、OSの案内に従ってインストールします。必要な場合だけ、取得に使ったブラウザー等からのアプリのインストールを許可してください。
3. 起動後の「TTDrawについて」で版と利用条件を確認します。

広告や別製品の配布ページではなく、上記の正規配布元を利用してください。ReleasesにはAPKのSHA-256と公開配布情報も添付します。署名の公開指紋は`d6ce1d565e02b351e178fb182d6f40260e04aac0e95ef9fa0ce7c082b7cba05f`です。

## 更新する

重要なデータをTTD（`.ttd`）へエクスポートしてから、同じ正規配布元の新しいAPKを開きます。同じアプリID・同じ配布署名・より大きい内部番号の版を使い、既存アプリを残したまま更新します。

更新できない場合は、まずアプリ版と取得元を確認し、[問い合わせ](mailto:info@toyo-craft.net)へご相談ください。過去の開発用APKは署名やアプリIDが異なる場合があります。既存データを退避せずにアプリを削除しないでください。

## Google Playへの移行

GitHubでの先行配布はPlay公開までの経路です。同じアプリID・配布署名と新しい番号で移行する方針ですが、実際のPlay配布経路の確認はPlay公開準備後に行います。Playの案内が掲載されるまでは、移行完了や自動更新対応を保証するものではありません。

## 保存条件

通常スケッチは30件を超えると古いものから自動整理されます。お気に入り・テンプレート等は対象外です。PNGは表示範囲の画像、TTDは編集可能な保存データの移行に使います。詳しくは[データの案内](https://github.com/toyo-craft/ttdraw/blob/main/docs/ja/data.md)を参照してください。
