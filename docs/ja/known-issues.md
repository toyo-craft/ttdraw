# 先行配布の位置付けと制限

- GitHub配布はGoogle Play公開までの先行経路です。版ごとの説明・既知事項は[Releases](https://github.com/toyo-craft/ttdraw/releases)を確認してください。
- Android 7.0（API24）以降を対象としますが、全端末・全OS版での同一動作を保証するものではありません。
- 配布版の確認範囲と追加事項は、各リリースの説明を参照してください。端末固有の性能・読み上げ・実Play移行の確認結果を、記載がないまま保証するものではありません。
- 通常スケッチは30件を超えると古いものから自動整理されます。お気に入り・テンプレート等は対象外です。
- PNGは現在の表示範囲の画像です。編集可能な全保存データのバックアップにはTTDを使います。
- 現行版はログイン・広告・アプリ内決済・提供者クラウド同期を行いません。将来の機能を現行提供済みと案内するものではありません。
- 同じIDでも開発用APKと正式配布APKでは署名が異なる場合があります。データを退避せず削除して更新しないでください。
- Web版は一般配布対象ではありません。公開サイトを模した非公式ページへのデータ入力は避け、正規の配布元を利用してください。

不具合は[Issues](https://github.com/toyo-craft/ttdraw/issues)へ、非公開の相談は[info@toyo-craft.net](mailto:info@toyo-craft.net)へお願いします。
